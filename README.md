# Weaver Home Building & Consulting website

The public site is https://whbcllc.com/ and is published from this repository through GitHub Pages. Keep CNAME and the current custom domain in place.

## Main pages

- index.html contains the homepage, portfolio, service areas, contact information and daily verse card.
- quote.html contains the two-step project request.
- careers.html contains the full employment application and original PDF download.
- small-projects.html and financing.html contain the project and Acorn Finance pages.
- The seven town pages contain local construction guidance.

## Shared behavior

Daily NIV verses are curated for building, foundations, wisdom and craftsmanship. daily-verse.js rotates them at midnight Eastern time. Preserve the verse attribution.

The native photo dialog supports Previous, Next, arrow keys and Escape, and returns focus to the thumbnail. Mobile quote links land at the form and preserve the selected project type.

Google Search Console uses the verification tag in the homepage head. Keep it in place after verification. sitemap.xml lists public content pages only.

A separate private activity report has not been connected. AppDeploy refused the new deployment because the current plan’s deployment window expired. Do not reuse Weaver Hydro’s report endpoint or search verification token for this site.
