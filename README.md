The public site is https://whbcllc.com/ and is published from this repository through GitHub Pages. Keep CNAME and the current custom domain in place.

## Main pages

- index.html contains the homepage, portfolio, service areas, contact information and daily verse card.
- quote.html contains the two-step project request.
- careers.html contains the full employment application and original PDF download.
- small-projects.html and financing.html contain the project and Acorn Finance pages.
- The seven town pages contain local construction guidance.
